# reverse-gps

Signature visual: the goal parsed into editable chips (role, city, country, company), then the top 3 to 5 routes as stepped cell paths from "You (VIT CSE + 2 yrs)" to the goal.
Each step is a labelled grid block with typical years; each route shows its people Count, typical years, a fit label and a tickable "Gaps to close" checklist.
The best-fitting route (fit first, then people) is inverted to black by default; "Highlight" moves the inversion to another route.
Supporting panels: skills common in the goal role that you do not list yet (what you already have is noted below), the shared routes graph, and any other section via SectionView.
Thin or widened results explain warmly and offer a one-click widen (drop the city or company); next-step buttons and the coverage line close the view.
